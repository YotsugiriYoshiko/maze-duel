# 盲走迷宫：双人在线网页游戏

这是一个最小可玩版本（MVP），使用 HTML/CSS/JavaScript + Node.js + Socket.IO。

## 已实现的规则

- 两人通过房间号码进入同一局游戏。
- 两人都进入后，开始 60 秒迷宫构筑倒计时。
- 每位玩家只能编辑自己的 12×12 迷宫；点击格子添加墙壁，再次点击移除。
- 起点（1,1）和终点（12,12）不能放墙；每次添加墙壁后，服务器用 BFS 检查起点到终点是否仍然连通。
- 双方都准备好时立即开始；否则 60 秒结束后自动开始。
- 服务器随机决定先手，双方严格轮流行动，每次移动一格。
- 玩家只会收到自己已经撞到的墙壁，不会收到对方迷宫中尚未发现的墙壁数据。
- 撞墙显示“你碰壁了！”，位置不变并结束本回合。
- 抵达（12,12）立即结束游戏，之后双方迷宫完整公开。
- 支持方向按钮、键盘方向键，以及点击相邻格子移动。
- 浏览器刷新后会尝试通过本地房间凭证重新加入。

## 本地启动

需要安装 Node.js 20 或更新版本。

```bash
npm install
npm start
```

然后在浏览器打开：

```text
http://localhost:3000
```

两个人在同一台电脑测试时，可以用两个不同浏览器窗口分别创建/加入房间。远程朋友需要部署到公网，不能只访问你电脑上的 localhost。

## 部署到 Render

1. 把整个 `maze-duel` 文件夹上传到你自己的 GitHub 仓库。
2. 登录 Render，选择 **New → Web Service**，连接刚才的 GitHub 仓库。
3. 如果仓库根目录就是本项目，填写：
   - Runtime / Language：Node
   - Build Command：`npm install`
   - Start Command：`npm start`
4. 创建服务，等待部署完成。Render 会给出一个 `https://……onrender.com` 的网址。
5. 把网址发给朋友。一个人创建房间，另一个人输入房间号码加入。

`PORT` 由 Render 自动提供，程序会监听 `0.0.0.0`。

## 当前版本的限制

- 房间状态保存在服务器内存中。服务器重新部署、重启或实例休眠后，正在进行的房间可能消失；适合朋友之间试玩，不适合长期运营。
- Render 免费 Web Service 会在一段时间没有请求后休眠，首次打开或重新连接可能需要等待服务唤醒。
- 房间关闭后，两位玩家都会退出。
- 这是朋友间的轻量娱乐原型，尚未加入持久化数据库、账号系统、观战、聊天和断线超时判负等功能。

## 核心文件

- `server.js`：房间管理、迷宫合法性检查、回合控制与隐藏信息隔离。
- `public/index.html`：页面结构。
- `public/style.css`：界面样式。
- `public/client.js`：浏览器交互和棋盘绘制。
